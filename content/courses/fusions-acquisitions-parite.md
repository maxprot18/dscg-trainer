# Fusions-acquisitions : parité d'échange, synergies, création de valeur

**Références :** Code de commerce, livre II, titre III, chapitre VI (fusions et scissions) ; méthodes d'évaluation financière (patrimoniale, rendement, DCF, comparables)

**Parité d'échange** = valeur unitaire de l'action absorbée / valeur unitaire de l'action absorbante. Elle fixe le nombre d'actions de l'absorbante remises pour une action de l'absorbée.
- Valeurs déterminées selon une approche multicritère (actif net corrigé, valeur de rendement, DCF, multiples), avec les mêmes méthodes pour les deux sociétés.
- Nombre d'actions à émettre = nombre d'actions de l'absorbée échangées × parité. Les actions de l'absorbée détenues par l'absorbante ne sont pas échangées.

**Synergies** : de coûts (achats, fonctions support) ou de revenus. Leur valeur = valeur actuelle des gains nets d'impôt − coûts d'intégration. Prix maximal pour l'acquéreur = valeur autonome de la cible + valeur des synergies ; la prime versée partage les synergies.

**Création de valeur** : l'opération crée de la valeur pour l'acquéreur si la valeur des synergies dépasse la prime payée.

**Effet relutif / dilutif sur le BPA** : la variation du BPA dépend des PER retenus dans la parité. Absorber une société dont le PER retenu est plus faible augmente mécaniquement le BPA (effet bootstrap), sans création de valeur.

**Formules clés :** parité = V_absorbée / V_absorbante ; BPA post-fusion = (RN_A + RN_B + synergies) / (N_A + actions émises)

## À retenir
- Ne pas inverser la parité : on divise la valeur de l'absorbée par celle de l'absorbante.
- Un BPA en hausse ne prouve pas la création de valeur.
- Intégrer les coûts d'intégration dans la valeur des synergies.
