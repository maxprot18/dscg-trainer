# False friends and translation pitfalls in accounting and finance

**References:** IAS 37 §10 ; IFRS 9 appendix A ("loss allowance") ; IAS 36 §6 ; IAS 1 §7 (règlement UE 2023/1803) ; usual UK/US professional terminology

**Provision ≠ provision**
- In IFRS English, a provision is a liability of uncertain timing or amount (IAS 37 §10): *provision pour litiges* → provision for legal claims (correct).
- A French *dépréciation* (or old-style *provision pour dépréciation*) of an asset is an impairment loss; on receivables, IFRS 9 speaks of a loss allowance. Never "depreciation of receivables".
- A "reserve" is a component of equity, not a provision.

**Usual pitfalls** (French → correct English, *wrong translation*)
- *résultat* → profit/loss, net income (*result*) ; *résultat d'exploitation* → operating profit (*exploitation result*)
- *chiffre d'affaires* → revenue, turnover (*business figure*)
- *exercice* → financial year, FY (*exercise*) ; *bilan* → balance sheet (*bilan*)
- *charges* → expenses (in English, charges are fees or levies) ; *produits* → income, revenue (*products*)
- *actif / passif* → assets / equity and liabilities ; *capitaux propres* → equity
- *commissaire aux comptes* → statutory auditor (*commissioner*) ; *expert-comptable* → chartered accountant
- *amortissement* → depreciation or amortisation ; *dépréciation* → impairment ; *plus-value de cession* → gain on disposal
- *actions / obligations* → shares / bonds (*obligations* means commitments) ; *trésorerie* → cash (treasury = the function)

## Key points
- Translate *provision* by "provision" only when it is a liability; otherwise use impairment or (loss) allowance.
- "Résultat" is never "result" in a set of accounts.
- In English, "depreciation" is a systematic allocation (*amortissement*), not a loss in value.
- *Éventuellement* means possibly, *actuellement* currently: avoid "eventually" and "actually".
